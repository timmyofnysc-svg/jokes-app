# Show and Hide Text App

## 📌 Overview
This project is a simple web application that demonstrates how to show and hide text using JavaScript. It is part of a frontend assignment to practice DOM manipulation.

## ✨ Features
- Display text when the user clicks a button  
- Hide text when the user clicks another button  
- Interactive user interface  
- Beginner-friendly code structure  

## 🛠️ Technologies Used
- HTML5  
- JavaScript (DOM manipulation)  

## ⚙️ How It Works
The project uses JavaScript to access an HTML element by its ID and then updates its visibility or content when a button is clicked.

## ▶️ How to Run the Project
1. Download or clone the repository  
2. Open the project folder  
3. Double-click on `index.html` or open it in any browser  
4. Use the buttons to show or hide the text
